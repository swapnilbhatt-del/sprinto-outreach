Sprinto Outreach Pipeline

An agent that finds and researches B2B software companies, decides whether each fits Sprinto's ideal customer profile, finds the right person and a verified email, drafts a cited cold email, then handles the replies: proposing times, booking the meeting and learning from every outcome. Everything is sent only to the owner's own inbox.

How a company is judged

Four gates decide fit, one adds points

Gates run in this order. Any failed gate makes the company no-go. Any gate that can't be answered from evidence makes it needs-review; nothing passes on a guess. Every pass cites a quote and a source URL.

G1

B2B software

Sells software to businesses, quoted from the site or press.

G5

No SOC 2 / ISO yet

No SOC 2 Type II or ISO 27001 claim on the site, its certificate links, trust page or news.

G3

100–1,000 staff

A stated headcount within 24 months, or Hunter's size range.

G2

Series A–C

A named round within 36 months; not acquired, public or Series D+.

G4 · +3 points

Compliance pressure

A security or GRC job, SOC 2 "in progress", or a new security leader. Scores only since 10 Nov.

Research orderFree sources first (news, job boards, Wikidata), then Hunter, then the company's own pages. robots.txt is respected; logins and CAPTCHAs are never bypassed.
Hard limits per company3 research passes, 8 page fetches, 16 free API calls, 12 LLM calls. Hunter: 50 credits per billing cycle, checked live before every run, results cached.
Contact and emailHighest-ranked title with a verified email (CISO down to CEO). If Hunter has none, founders or CEOs named in news are looked up with Hunter's Email Finder; only valid addresses count.

After the email is sent · L6

The reply agent, tested live on 18 Nov

A LangGraph state machine with five tools, each described by what it does, when to use it, when not to, and what it returns. Its state object is saved in the database after every check, so it resumes where it stopped. In the test the owner played the prospect by replying from the owner's own inbox; each check ran on the live site, triggered by the scheduler.

Getting better each send · L5

The feedback loop

Each draft collects three kinds of feedback: the reply outcome (recorded by the agent), the owner's 1–5 rating, and the edited version the owner would send. “Learn from feedback” asks the model for at most three short writing lessons, each citing the feedback that supports it. Lessons without evidence, longer than 30 words, or repeating an existing one are dropped. Only lessons the owner approves are added to the drafting prompt, and every new draft records which lessons it used, so its outcome becomes evidence about them.

On the live data the loop has three positive outcomes for one email and correctly proposes no lesson yet; it waits for ratings and edits rather than generalising from a single draft.

Limits

What it doesn't do

  • Discovery is news-led. It finds companies with recent funding headlines; companies that raised quietly need to be pasted in.
  • Pages built only by JavaScript can't be read, so some trust pages and homepages leave a gate unanswered (Mozark, Omilia).
  • Bing News misses some older coverage, such as Rewaa's Dec 2025 Series B.
  • Free tiers set the pace: 50 Hunter credits per cycle and an occasionally overloaded Gemini.
  • Only Sprinto is set up as a seller. Other companies need their own researched profile.
  • HubSpot isn't connected to the agent yet, so meeting outcomes are handed to the owner to log by hand.
  • The prospect is simulated. Replies come from the owner's own inbox; nothing is sent to real prospects.
